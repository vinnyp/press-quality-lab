# Conformance collection specification 1.0: errata and notes

The files in `conformance-collection-1.0/` will be sealed and then not edited. The version policy in `collection-contract.md` (QE1) says that purely editorial corrections keep the version string `1.0` and are listed in a dated note. This is that note.

Nothing here changes what a collector records or which exit code the engine ends with. Where an entry and a binding rule appear to differ, the rule is right.

The specification is frozen for review and not yet sealed, so this note has no entries yet.
